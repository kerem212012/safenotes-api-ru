# Задание

- Храни пользователей и заметки в SQLModel, пароль — только как Argon2-хеш.
- Реализуй регистрацию с конфликтом `409` и OAuth2 password login.
- Подписывай короткоживущий JWT с `sub` и `exp`.
- Создай dependency текущего пользователя с одинаковым безопасным ответом `401`.
- Разрешай читать и удалять только собственные заметки.
- Проверь изоляцию двух пользователей и `uv run pytest`.
